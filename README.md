# Case OrbitShop

Código que reproduz todos os números do memo do case individual da Peers (Digital Consulting). A análise cobre as perguntas Q2 a Q7 sobre a base `Base_Dados_OrbitShop.xlsx` (15.000 pedidos, de janeiro de 2023 a dezembro de 2024).

## Conteúdo da entrega

```
README.md
Memo.pdf                    
Case_OrbitShop.ipynb        
```

## Como executar

1. Coloque `Base_Dados_OrbitShop.xlsx` na mesma pasta do notebook.
2. Instale o Python 3.xx
3. Instale as dependências:
   ```
   pip install pandas numpy matplotlib scipy openpyxl
   ```
5. Abra `Case_OrbitShop.ipynb` e execute as células **em ordem** (Kernel > Restart & Run All). Também funciona no Google Colab, enviando a base para o ambiente.

Dica: Caso esteja visualizando o notebook no Colab, é possível navegar rapidamente entre as seções utilizando o índice lateral.
